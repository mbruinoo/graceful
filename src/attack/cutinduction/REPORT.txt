SUMMARY
GTC and Conjecture B remain open; nothing here proves them. I generalised the clean leaf (README Lemma 8) to a "clean set" of labels and proved: deleting a clean set preserves growth; disjoint clean sets stay clean; clean-leaf peeling has a unique core, so "greedily peelable" is the largest property closed under one leaf step back (it breaks at S(2,2,2), n=7). I then measured the hierarchy C(K) = placements dismantlable by clean sets of size at most K. C(2) contains every tree on n <= 17 except three (S(3,3,3); S(10,3,3) and one double-branch tree at n=17). Most important outcome: no fixed K survives. The step number of S(L,L,L) is 1,2,3,2,2,5,3,6,6 for L=1..9, so S(6,6,6) (n=19) is outside C(4) and S(8,8,8) (n=25) outside C(5). The cut induction therefore needs unbounded step size on equal-leg spiders.

===== CLAIM 0 [proved]
STATEMENT
Setting: placements as in README section 1 (labels 1..n, bracket k = {p_k, p_k+k}); growth placement as in README section 2 (for every k the brackets n-1..k form a connected tree). DEFINITION. For a growth placement p on n labels and a set R of labels with n-|R| >= 2, call a bracket an R-bracket if it has a foot in R. R is a CLEAN SET if (1) exactly |R| brackets are R-brackets, and (2) every other bracket has strictly between its feet exactly as many labels of R as there are R-brackets shorter than it. (|R|=1 is exactly the clean leaf of README section 9.) Write p\R for: delete the labels of R and the R-brackets, relabel the rest order-preservingly.
(T1) If R is clean then p\R is a growth placement of T-R, and kept brackets keep their order by length. Conversely if (1) holds and p\R is a placement in which kept brackets keep their length order, then (2) holds.
(T2) If R1, R2 are disjoint clean sets of p and n-|R1|-|R2| >= 2, then the image of R2 is a clean set of p\R1 (so the union is clean and the two deletions commute).
(T3) Unique core: repeatedly deleting clean leaves until none is left (or 2 labels remain) ends in the same placement whatever order is used. Hence 'peelable to the single edge by clean leaves' (the closure of Lemma 8 insertion from K2) is decided greedily, and it is the largest class P of growth placements in which every member on >= 3 vertices has a clean leaf whose deletion stays in P.
(T4) For n >= 3 the following are equivalent for a growth placement: every leaf is clean; the leaf end of the shortest bracket is clean; the placement is a staircase.

EVIDENCE
lemma_check.cpp, brute force from the definitions: T1, its converse, T2 and T4 have 0 violations over all growth placements with n <= 9 and ALL label sets R (83,486 clean sets, 246,224 disjoint clean pairs at n=9), and for n <= 12 with |R| <= 3 (214,600 placements, 1,389,762 clean sets, 9,430,064 disjoint pairs at n=12). confluence.cpp: T3 has 0 violations for all growth placements n <= 12 (384,608 ordered pairs of clean leaves at n=12; core computed along every first step and compared). Non-order-preserving growth restrictions do exist (16 at n=7, 179,632 at n=12 with |R|<=3), so the converse of T1 needs the order hypothesis. Core statistics (n=12): 214,600 growth placements, 76,120 primitive (no clean leaf); core sizes 2:11600 5:5992 7:8464 8:11274 9:18740 10:30398 11:52012 12:76120. Primitive counts n=5..12: 2, 0, 24, 64, 430, 2058, 13098, 76120.

PROOF
T1. By (1) the kept brackets are n-1-|R| edges of the tree T on the n-|R| kept labels: a forest with (vertices - 1) edges, hence the tree T[S], S = complement of R. A kept bracket of length l has new length l - #(labels of R strictly between its feet) = l - #(R-brackets shorter than it) by (2). Since lengths 1..l all occur, this equals the number of kept brackets of length <= l, i.e. its rank among kept brackets. So new lengths are 1..n-|R|-1, each once (a placement), and the length order is preserved. Growth: fix m and let k be the old length of the kept bracket of rank m. Kept brackets of new length >= m are exactly the edges lying in both G_k (the brackets of old length >= k, a connected subtree by the definition of growth) and T[S]. For two such edges, the unique path of T joining them lies in G_k and in T[S] (a connected subgraph of a tree contains the path between any two of its vertices), so these edges form a connected graph. This holds for every m, which is the definition of growth. Converse: if kept brackets keep their order and the new lengths are 1..n-|R|-1, the new length of a kept bracket is its rank, so the number of R-labels it jumps is l - rank = #(R-brackets shorter than it).
T2. Let S1, S2 be the complements and S their intersection, |S| >= 2. T[S1], T[S2] are subtrees by (1); for u, v in S the T-path between them lies in both, so T[S] is a tree with |S|-1 edges. Hence the number of brackets with a foot in R1 or R2 is n-1-(|S|-1) = |R1|+|R2|; as there are |R1| R1-brackets and |R2| R2-brackets, no bracket is both. So all R2-brackets survive in p\R1 and are exactly its brackets with a foot in the image of R2: condition (1). A bracket of p\R1 that is not one of them jumps the same number of image-R2 labels as it jumped R2 labels in p (relabelling is order-preserving on labels), namely #(R2-brackets shorter than it in p), and by T1 length order among kept brackets is unchanged in p\R1: condition (2).
T3. For n >= 4 and two distinct clean leaves L1, L2, T2 with singletons gives: L2 is still a clean leaf after deleting L1 and vice versa, and both orders give p\{L1,L2}. For n = 3 both growth placements have only clean leaves and every deletion gives the single edge. Deletion strictly decreases n, so the process terminates and is locally confluent; by Newman's lemma the terminal placement is unique. Maximality: if P is closed under one clean-leaf step back, induction on n shows every member peels to the single edge.
T4. Staircase => every leaf clean: in a staircase the brackets are nested intervals I_1 in I_2 in ... each sharing a foot with the next. A leaf L is a foot of exactly one bracket I_j; shorter brackets lie inside I_j and do not jump its endpoint L; longer ones contain I_j and do not have L as a foot, so L is interior to them. Every leaf clean => the leaf end of bracket 1 is clean (bracket 1 is pendant in a growth placement). If the leaf end L of bracket 1 is clean, every other bracket jumps L; deleting L gives (README Lemma 8) a growth placement all of whose brackets jump one common point, a staircase by README Theorem 9. Re-opening the gap keeps left feet and the nesting of brackets 2..n-1; bracket 2 jumps L with length 2, so it is {L-1, L+1}, and bracket 1 is {L-1,L} or {L,L+1}: p_1 - p_2 is 0 or 1, so p is a staircase.

STATEMENT

Forwards: p is obtained from a member of C(K) by opening at most K gaps and adding one new vertex per gap so that old brackets keep their length order. C(1) is the Lemma 8 closure of README section 9; by claim 1 (T1) every member of every C(K) is a growth placement. OBSERVATION (exhaustive, n <= 17). ===== CLAIM 2 [counterexample]
STATEMENT
No fixed step size works: for each K <= 5 there is a spider that has growth placements but none in C(K) (C(K) as in claim 2). Define the step number kappa(T) as the least K such that T has a growth placement in C(K). Then kappa(S(2,2,2)) = 2 (n=7), kappa(S(3,3,3)) = 3 (n=10), kappa(S(6,6,6)) = 5 (n=19), kappa(S(8,8,8)) = 6 (n=25), kappa(S(9,9,9)) = 6 (n=28). So 'every tree has a growth placement in C(K)' is false for K=1 (n=7), K=2 (n=10), K=3 and K=4 (n=19 at the latest; no failure of K=3 for all trees n <= 14 and all 3-legged spiders n <= 18), and K=5 (n=25 at the latest). Full list for three equal legs of length L=1..9: kappa = 1, 2, 3, 2, 2, 5, 3, 6, 6. Whether kappa is unbounded over all trees is not proved; the data suggests it grows irregularly.
