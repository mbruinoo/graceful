SUMMARY
Nothing here proves GTC or Conjecture B. I defined relaxed growth labelings (labels in [1,N], N >= n, distinct lengths decreasing away from the root) and simulated a one-pass longest-first greedy for n = 200..2000. It never succeeds at eps = 0 from the centroid root and needs about 6-10% slack on random trees, scaling linearly in n. Stalls occur because pending parents sit at the ends of the label range while free labels sit in the middle. Most important outcome: exhaustively for n <= 19, every vertex of every tree can carry label 1 in a relaxed growth labeling with one spare label (N = n+1). The only proved result is an elementary N <= 2n-2 bound for every root. None of the three papers' processes adapts directly: growth fixes the edge-label order, which removes the randomness they rely on.

DEAD ENDS
1. Adapting Adamaszek-Allen-Grosu-Hladky (arXiv:1608.01577, outline in their Section 3 read). Their process labels one vertex at a time and keeps the available vertex labels A_t and available edge labels B_t looking like uniform random subsets; a child gets a label in a short interval complementary to its parent's, so the edge label is roughly |N - 2*label(parent)| and is uniform. Growth breaks exactly this invariant: B_t must be an initial segment {1..l_t}, so the edge label is dictated by time, not by the parent's position. The parent of the vertex placed at time t must then sit within reach of the current fronts, and the vertices carrying the longest delta*n lengths are confined to two end intervals of total size 2*delta*N (window lemma) instead of being spread uniformly. With total slack eps*n the process has on average only about 2(1+eps) candidate labels per (parent, step), against an interval of order n candidates in their proof. Smallest obstruction: the path rooted at its middle vertex, where the one-pass process fails 100/100 for all eps <= 30% at n = 1000.
2. Adapting Letzter-Pokrovskiy-Williams (arXiv:2511.11331, strategy in their Section 3 read). They delete a small waste set W, write the rest as high-degree vertices plus d copies of a small forest F, and embed each edge of F as a rainbow matching of size d; W is placed arbitrarily at the end, which is where colour repeats come from. For growth, the matching of a lower edge of F must use lengths below the matching above it in every copy, i.e. each matching needs a block of consecutive lengths. A matching between two label sets whose differences form an interval forces arithmetic progressions whose step changes by 1 from one level to the next (step 0 at the hub, 1 for its children, 2 for grandchildren), so vertex sets are progressively sparser and must interleave exactly. For d legs of length 2 this gives range about 1.5n immediately, and exactness runs into the arithmetic obstruction of README Lemma 11. The waste step breaks too: a vertex of W placed arbitrarily violates monotonicity on its whole subtree, not on one edge. Not developed further.
3. Montgomery-Pokrovskiy-Sudakov (arXiv:2001.02665, outline only): rainbow copies in the near-distance colouring of K_{2n+1}; colours are cyclic distances in a range of 2n+1 and are consumed in no order; the finishing absorbers and switchers exchange colours between edges, which is incompatible with a fixed length order. Their split 'many leaves versus many bare paths' does mirror the simulation: bushy random trees are the easy case for longest-first, while paths from the middle and few-leg spiders are where it behaves erratically.
4. My first heuristic was wrong: treating free labels as random predicted that slack of order sqrt(n log n) would suffice. The simulation shows linear slack. The error: free labels are not random relative to the waiting parents (end zones are full, free labels are central).
5. Better tie-breaking helps only by a constant factor (0.14n -> 0.10n -> about 0.065n). The limit is the 'always take the longest feasible length' rule itself; no o(n)-slack one-pass rule was found.
6. A monotone two-block scheme (even depth low, odd depth high, sums increasing) costs, at each change of parent, the amount by which the new parent is deeper behind its block front than the previous one; this is zero only for caterpillar-like expansion orders, and a rough count gives of order n extra labels for breadth-first and n log n for depth-first on a complete binary tree. So this route does not get below 2n without leaving and refilling holes.
7. 'Every vertex with a leaf neighbour is an anchor' fails at n = 9, and no fixed (unused label, unused length) pattern explains the slack-1 labelings (relaxpattern.cpp, n = 8..12).

===== CLAIM 0 [verified-only]
STATEMENT
Definition: a relaxed growth labeling of a rooted tree (T,r) with range N is an injective f: V -> {1..N} with f(r)=1, pairwise distinct edge lengths |f(u)-f(v)|, and lengths strictly decreasing along every path away from r. For N = n this is exactly a growth placement with anchor r (README Theorem 7). OBSERVATION (one-spare-label anchors): for every tree T on 5 <= n <= 19 vertices and EVERY vertex r of T, (T,r) has a relaxed growth labeling with range N = n+1. Equivalently, every non-anchor of README section 7 becomes an anchor once one label and one length may stay unused. Proposed falsifiable strengthening (Conjecture, not proved): this holds for all n.

EVIDENCE
src/attack/asymptotic/relaxmin.cpp, complete longest-first backtracking over all free trees (src/treegen.h) and all roots; every labeling found is re-checked from the definition (0 verification failures). (tree,root) pairs needing slack exactly 1, for n = 6..19: 1, 4, 6, 11, 19, 21, 37, 54, 84, 117, 154, 198, 264, 324. Pairs needing slack >= 2: 0 for every n <= 19 (6,041,145 pairs over 317,955 trees at n = 19). The slack-0 failure counts reproduce the README non-anchor counts at n = 8, 10, 12, 14 (6, 19, 37, 84), which were computed by a different program (anchors.cpp). n = 20 was started but did not finish inside the 20-minute cap, so it is not claimed. Side facts from the same runs: every tree on n <= 19 has at least one slack-0 root; roots needing slack have degree <= 3 (the first of degree 3 is at n = 11); the tempting shortcut 'every vertex with a leaf neighbour is an anchor' FAILS, first at n = 9 (2 rooted pairs; 6 at n = 18). No single (unused label, unused length) pattern serves all non-anchors (relaxpattern.cpp, n = 8..12). Logs: run_relaxmin_5.log .. run_relaxmin_19.log.

PROOF
No proof. Sketch of why it is not trivial: if r is an anchor of T plus a new leaf at r, deleting that leaf gives a slack-1 labeling of (T,r); but that route fails for the vertices with a leaf neighbour that are non-anchors (n = 9 on), so the slack-1 labelings found are not all of this form.


===== CLAIM 1 [verified-only]
STATEMENT
SIMULATION (one-pass randomized longest-first process, no backtracking; root at label 1; at each step take the largest length l below the previous one for which some placed vertex with an unplaced child has y+l or y-l free in [1,N], then break ties by a policy). With N = (1+eps)n: (a) at eps = 0 the process succeeded in 0 of 100 trials for every tree type, size and policy tried from the centroid root; (b) for uniform random (Pruefer) trees the least slack at which a run succeeds is linear in n, about 0.14n for 'largest subtree first' and about 0.06-0.07n for the best policy tried ('parents about to lose reach first'); (c) whenever it stalls, the parents still waiting sit at the ends of the label range and the free labels sit in the middle. LEMMA (window, proved): in any relaxed growth labeling, once an edge of length L has been placed, every later child of a vertex labelled y receives a label in (y-L, y+L); and an edge of length l has its smaller endpoint <= N-l and its larger endpoint >= l+1.

EVIDENCE
src/attack/asymptotic/greedy.cpp, run_grid.sh -> run_grid.log (13 tree types x n in {200,500,1000,2000} x 10 values of eps x 3 policies, 100 trials per cell, every success re-verified from the definition, 0 verification failures), plus run_extra.log. Success counts out of 100 at eps = 0%, 5%, 10%, 15%, 20%, 30% for n = 1000, centroid root. Policy 6 (critical parents first, THETA=5): Pruefer 0/40/90/100/100/100; random recursive 0/14/100/100/100/100; preferential attachment 0/35/100/100/100/100; random max-degree-3 0/67/100/100/100/100; random lobster 0/0/42/99/100/100; random caterpillar 0/39/45/49/74/92; heap-shaped binary 0/0/0/92/100/100; comb with teeth of length 3: 0/12/100/100/100/100; teeth of length 10: 0/98/100/100/100/100; spider 3 legs 0/87/57/93/71/68; spider 10 legs 0/39/51/64/75/91; spider 50 legs 0/74/19/67/25/96; path from its middle 0/0/0/0/0/0 (57 at eps = 50%, 100 at eps = 100%). All 156 cells reached 100/100 at eps = 100%. Policy 1 (largest subtree first) on Pruefer trees, n = 1000: 0/0/4/63/100/100; policy 0 (uniform random): 0/0/9/24/22/60. Least slack for Pruefer trees (doubling plus bisection, not exactly monotone), policy 6, 100 trees each: median 15, 32, 57, 137 at n = 200, 500, 1000, 2000 (ratio 0.075, 0.064, 0.057, 0.069); policy 1, 60 trees each: mean 27.1, 67.3, 135.4, 284.6 (ratio about 0.14); policy 5: mean 17.9, 48.7, 97.9, 192.5 (about 0.097). Other types at n = 1000, policy 6: median 59 (recursive), 47 (max-degree-3), 57 (preferential attachment). Root choice: Pruefer n = 1000, policy 6, random leaf root 36/95/100 and random root 48/89/100 at eps = 5/10/15%; a path from a leaf succeeds at eps = 0 (100/100, the zigzag); random caterpillars from a leaf root fail 0/100 up to eps = 10% under policy 1 although staircases exist, so the process is not a staircase finder. Stall diagnosis (Pruefer, n = 1000, slack 50, policy 1, 200 failed runs, one-off instrumented copy, not kept in the repo): of 3,114 stalled parents, 79.7% had labels in the outer 10% of [1,N] and 98.0% in the outer 20%; of 13,221 free labels, 0.05% lay in the outer 10% and 3.7% in the outer 20%; median number of vertices still unplaced at the stall: 18.

PROOF
Proof of the window lemma only (the numbers are simulation). Lengths decrease away from the root, so the edges of length >= L form a subtree containing the root, and an edge placed after L has length l < L; the child's label is y+l or y-l, hence within distance L-1 of y. For the second part, two labels in [1,N] at distance l satisfy min <= N-l and max >= l+1. Consequence (heuristic, not proved): vertices placed while l > N/2 lie in the two end zones; the remaining slack only ever lets the process look Delta lengths below the current one, so a parent at depth d behind its block front has all its reachable labels used unless it is served while l is still larger than d. This is why the needed slack is a constant fraction of n and not o(n) for this process.


===== CLAIM 2 [proved]
STATEMENT
THEOREM (elementary upper bound, every root). For every tree T on n >= 2 vertices and every vertex r there is a relaxed growth labeling of (T,r) with range N <= 2n-2: an injective f: V -> {1..N} with f(r)=1, pairwise distinct edge lengths, and lengths strictly decreasing along every path away from r. Explicitly, with sigma the breadth-first (queue) index from r (sigma(r)=0), put f(v) = 1+sigma(v) at even depth, f(v) = N+1-sigma(v) at odd depth, where N = 1 + max(sigma on even depth) + max(sigma on odd depth). This is a baseline in the style of the classical 2n-type range-relaxed labelings; no novelty is claimed, and the gap to claim 1 (slack 1 observed versus slack n-2 proved) is the open problem.

EVIDENCE
src/attack/asymptotic/bfs_bound_check.py checks the construction from the definition: all labelled trees on n = 2..7 with every root (126,125 rooted trees) and 2,000 random trees with 8 <= n <= 300 (14,201 rooted trees); all pass; the largest N/n seen is 1.993, so the construction itself really uses nearly 2n.

PROOF
Let me and mo be the largest sigma on even and odd depth; they are distinct indices in 0..n-1, so me+mo <= 2n-3 and N <= 2n-2; odd depth is non-empty since n >= 2. Range and injectivity: even labels lie in [1, 1+me]; odd vertices have sigma >= 1, so odd labels lie in [N+1-mo, N] = [2+me, N]; sigma is injective within each class. Lengths: an edge joins a parent p and child c of opposite parity, so its length is (N+1-sigma(odd end)) - (1+sigma(even end)) = N - sigma(p) - sigma(c) >= N - me - mo = 1. Distinctness: in queue order, sigma(c) < sigma(c') implies sigma(parent(c)) <= sigma(parent(c')), so s(c) = sigma(c) + sigma(parent(c)) is strictly increasing in sigma(c); different edges have different s, hence different lengths. Decrease away from the root: if c' is a child of c and c a child of p, then sigma(c') > sigma(c) > sigma(p), so s(c') > s(c) and the lower edge is shorter. Finally f(r) = 1 + 0 = 1. QED.
